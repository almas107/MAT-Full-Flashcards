# Physics MAT Flashcards (Anki)

Anki decks for **পদার্থবিজ্ঞান ১ম ও ২য় পত্র**, one `.apkg` per chapter, written in the style of DGME MAT/DAT questions.

## Sources
1. **প্রশ্নব্যাংক (Medical Master QB)** — every chapter's topic-wise questions were covered first (practice-test pages skipped as repeats).
2. **Past MAT/DAT questions** from the two uploaded `.md` files — re-bucketed to the correct chapter and tagged with years.
3. **Textbook (লাল-সবুজে দাগানো)** — only red/green highlighted lines, red/green bracketed paragraphs and highlighted worked examples/math.

Where the QB and the textbook disagree, the card gives the book value and notes the QB value.

## Card style
- Front: a direct recall question (Bengali). Back: short answer; list-type questions (বৈশিষ্ট্য, শর্ত, ব্যবহার) list every item.
- Negative questions ("কোনটি সঠিক নয়") are turned positive: the back lists the true facts, then `✗ … — ভুল` for the trap option.
- Math cards keep the numbers; the back gives the answer plus the formula or key step.
- Cards asked in a past exam carry a **PYQ** tag and the year line (e.g. `MAT 22-23, DAT 17-18`). Each chapter deck has topic subdecks.
- No duplicates within a chapter (the build enforces this) or across chapters (checked by hand).

## Rebuilding
Card text lives in `source/p1_chNN.txt` / `source/p2_chNN.txt`:

```
# subdeck name
Q: question
A: answer || line break inside answer
Y: MAT 22-23, DAT 17-18      (optional)
```

```
cd "Physics Flashcards/source"
pip install genanki
python3 build_decks.py p2_06      # one chapter
```

The build fails if two cards in a chapter have the same front.
